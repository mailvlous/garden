#### analisis sifat keputusan
- deskriptif=menjelaskan keadaan saat ini
- diagnostic=menjelaskan mengapa terjadi masalah
- predictive=memprediksi hasil masa depan
- prescriptive=menyarankan upaya terbaik untuk masa depan

### data science
perilaku dan pemaknaan data, kebutuhan pengambilan keputusan

### standar proses data mining - CRISP DM
Cross-Industry Standard Process for Data Mining.  
six connected phases, with iteration between them rather than a one-way checklist
![image](/assets/image-20261027162137-8f0f88c6.png)

#### langkah pengembangan
1. analisis kebutuhan
    - pemahaman bisnis  
        - kebutuhan pemakai/pengguna  
          siapa pengguna? data apa?
        - kebutuhan sistem
          sistem apa? untuk apa? bagaimana prosesnya?
        - identifikasi & pemahaman permasalahan
    - pemahaman data
        - mengumpulkan data  
          data apa? berapa banyak?
        - menelaah data  
          karakteristik, relaasi antardata
        - memvalidasi data  
          kualitas data
2. pengembangan model
    - persiapan data  
        - memilih dan memilha data
        - membersihkan data
        - menkonstruksi data(menambahkan fitur dan transformasi)
        - integrasi data(menggabungkan data)
    - pemodelan
        - knowledge discovery
        - membangun skenario pemodelan(penentuan metode analisis, penentuan algoritma, pemisahan data)
    - pengujiaan model
        - mengukur performa model
3. penggunaan model

### metoda analisis
- regresi, memprediksi, nilai kontinu
- clustering, mengelompokan berdasarkan kesamaan
- klasifiasi, memprediksi kelas/kategori dari suatu kasus
- asosisasi, memprediksi suatu kumpulan event atau item yang akan terjadi secara bersamaan

### data mining
proses menemukan discovering pola dalam kumpulan dataset
