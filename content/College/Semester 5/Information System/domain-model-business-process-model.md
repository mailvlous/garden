### domain model

dari sudut pandang object oriented analysis and design  

..representation of real-situation conceptual classe in a domain, not of software object.  

*object is everything(also process), ditentukan oleh atribut

- object oriente analysis is concerned with creating description of the domain from the persepective objects. There is identification of concept, attributes and association
- the result can be expressed in a domain model that shows noteworthy domain conecpts of an objects

- a conceptual class maybe considered in terms of its:
    - symbols: words or image s represents conceptual class
    - intension: the definition of a conceptual class
    - extension: the set of exa,ples to which the conceptual class applies

*conceptual model != data model

- how to create a domain model?
    - reuse or modify existing models
    - use a cateory list
    - identify noun phrases

attributes vs classes  
- attributes dapat diisi dengan text/angka  


apakah domain model = data model? !=
- data model menunjukan data persistent/informasi yang akan disimpan
- class dalam coneptual model tidak harus memiliki atribut
- class dalam conceptual model tidak harus menyimpan informasi
